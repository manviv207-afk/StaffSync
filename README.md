# StaffSync

StaffSync is a staff management web app where employees can view their attendance, leave requests, announcements, and training, while managers can manage everything.

## Features

- Login and Signup
- Attendance tracking
- Leave requests
- Announcements
- Training management

## Tech Stack

- Frontend: React + Vite
- Backend: Node.js + Express
- Database: MongoDB

## Run Locally

1. Create a `.env` file in the `backend` folder and add your values (PORT, MONGO_URI, JWT_SECRET, FRONTEND_URL)
2. Backend: `cd backend`, `npm install`, `npm start`
3. Frontend: `cd frontend`, `npm install`, `npm run dev`
4. Open `http://localhost:5173` in your browser
